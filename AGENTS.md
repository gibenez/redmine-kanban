## Commit messages

Always prefix every commit message with a type label, using `<type>: <description>` (for example, `chore: update dependencies`, `fix: handle missing data`, or `bugfix: correct card ordering`). Choose the label that matches the change, such as `feat`, `fix`, `bugfix`, `chore`, `docs`, `refactor`, or `test`.
